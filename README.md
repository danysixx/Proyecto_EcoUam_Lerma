###  Sobre el Proyecto
Plataforma de bajo costo para la automatización, procesamiento y visualización de datos socioambientales sobre la gestión de residuos sólidos en Lerma, Estado de México.

- **Captura:** ODK Collect / ODK Central REST API
- **Procesamiento:** Módulos de automatización en Python
- **Despliegue:** Dashboard interactivo en Huawei Cloud ECS
